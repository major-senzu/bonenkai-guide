日程は2026年12月12日・13日・20日の候補、18:30開始は予定です。会場・参加者・座席は未確定です。座席図は構成見本で、実際の配置ではありません。

## 更新方法

- ルートの `index.html` を編集します。ビルドや外部ライブラリは不要です。
- 日付・集合時刻・開始終了時刻・店舗情報は、確定した情報のみ掲載します。
- `guideData` の `venueName`、`venueAddress`、`googleMapsUrl` を更新すると会場リンクが有効になります。
- `guideData.participants` に `{name: '掲載する表示名', seat: 'A-1'}` の形式で確定参加者を登録すると名前検索が有効になります。
- 日程アンケートの回答から参加確定を推測しないでください。
- 会場レイアウト確定後、座席図を更新し、表示名と座席番号を照合してください。
